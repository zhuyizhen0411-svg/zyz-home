# 评测数据目录说明

这个目录放的是**跑测试用的题集和跑出来的结果**（机器读的 JSON），
对应的人读报告在 `文档/01-题库/` 和 `文档/02-实验过程与结果/`。

```
数据/评测/
├── 题库/
│   ├── 题库1-最初的10道题.json         第一批：用来做基线和前 6 步优化
│   └── 题库2-全新10道题.json           第二批：换公司/换指标/换问法，专门检验有没有过拟合
├── 结果/
│   ├── 结果1-基线-答对3题.json         第 1 次测：3/10
│   ├── 结果2-优化后-答对7题.json       优化后重测同一批题：7/10
│   ├── 结果3-换全新题-答对4题.json     换第二批题：4/10（暴露过拟合）
│   └── 结果4-通用兜底后-答对7题.json   加通用兜底后重测：7/10
└── 过程产物/                            各步骤的中间结果，按「第0X步」命名
```

## 怎么重新跑

```bash
# 跑第一批题（默认）
python 代码/run_eval.py

# 跑第二批题
python 代码/run_eval.py --questions 数据/评测/题库/题库2-全新10道题.json \
                           --out 数据/评测/结果/结果4-通用兜底后-答对7题.json

# 只跑第 6、7、8 题
python 代码/run_eval.py --questions 数据/评测/题库/题库2-全新10道题.json --ids 6,7,8

# 只看召回、不生成回答（很快）
python 代码/run_eval.py --no-llm
```

**结果 JSON 里每题都有**：路由类型、识别到的公司/年份/报告类型、
召回块清单与来源、最终回答、引用块、每个数字的可追溯状态、公司覆盖检查。
